老師／家長：怎麼放到主畫面

把這一頁加到主畫面一次就好：兩個遊戲都在裡面，全螢幕、只要登入一次。

iPad／iPhone

  1. 用 Safari 打開這一頁。
  2. 按「分享」按鈕 → 「加入主畫面」。
  3. 從主畫面的 Arice 圖示打開，登入後選遊戲。

Android 手機／平板

  1. 用 Chrome 打開這一頁。
  2. 按右上角「⋮」→「加到主畫面」或「安裝應用程式」。

電腦

  1. 用 Chrome 或 Edge 打開，按網址列右邊的「安裝」圖示；或直接加到書籤。

想要兩個遊戲各一個圖示（iPad）

用 Safari 點這裡安裝描述檔，裝好到「設定 → 已下載描述檔」按安裝：學習島・勇者衝鋒。這樣每個圖示要各登入一次。
